# TIDE01 32秒产品推广视频案例

## 目标

从一份Word分镜和内嵌参考图开始，输出一条32秒、9:16、带英文男声和环境声的产品推广视频。

## 输入约束

- 3段各10秒的视频和2秒静帧尾卡；
- 同一人物、同一台手机、夜间木质码头；
- 第1段是人物自拍，第2段是几乎全黑的海面，第3段是产品微距；
- 上一段末帧作为下一段的参考首帧；
- 产品始终只有两枚按钮：左侧颗粒、右侧五条凸棱；
- 第3段只允许出现一根拇指；
- 需要生成并检查英语台词和环境声。

## 执行流程

1. Codex读取Word文档和参考图；
2. 识别产品真实性、手指解剖、人物口型和链式漂移风险；
3. 向用户确认产品、声音、尾卡和最大重试次数；
4. 先生成第3段产品技术样片；
5. 对样片抽帧，发现首版拇指没有明确到达右侧按钮；
6. 重写提示词，明确移动一个按钮宽度、到达按钮中心和单次持续按压；
7. 样片通过后，按第1段 → F1 → 第2段 → F2 → 第3段的顺序生成；
8. 抽取各段关键帧并检查人物、曝光、按钮、手指和红光；
9. 提取音轨并转写英语对白；
10. 修正画外音时间和末句语音；
11. 统一为1080×1920、30fps并制作2秒尾卡；
12. 输出准确32秒的H.264 + AAC MP4。

## 关键经验

### 先验证最难镜头

不要先生成整条片。产品结构、手指和灯光变化同时存在时，应先制作技术样片，确认模型是否能满足关键约束。

### 末帧链式衔接提高连续性

```text
S01 人物首帧 → 第1段 → F1
F1 → 第2段 → F2
F2 + 产品参考图 → 第3段
S11 → 2秒尾卡
```

链式衔接不能保证绝对无缝，但能减少人物、环境和运动方向突然变化。

### 生成正确不等于可交付

本案例还进行了：

- 抽帧检查；
- 英语语音转写；
- 画外音时间重排；
- 错误末句替换；
- 音量统一；
- 分辨率与帧率统一；
- 精确时长裁切。

## 结果规格

- 时长：32秒；
- 尺寸：1080×1920；
- 帧率：30fps；
- 视频：H.264；
- 音频：AAC，48kHz立体声；
- 音乐：无；
- 字幕：无；
- 尾卡：`NIGHTFIELD TIDE 01 / Keep the light on the task.`
